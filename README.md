# Devansh Singh Rajput — Personal Portfolio

A standalone, responsive personal portfolio website for Devansh Singh Rajput. This project is separate from WealthFolio.in.

## Included

- Single-page portfolio: introduction, areas of interest, WealthFolio and DivyaPath project showcases, experience, historical recognition, about, skills, education and contact.
- Responsive navigation, section links and mobile layout.
- Scroll progress, reveal-on-scroll transitions and reduced-motion support.
- Resume PDF download (`assets/Devansh-Singh-Resume.pdf`).
- No framework, build step, paid API or backend required.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Free hosting with GitHub Pages

1. Create a new GitHub repository, for example `devansh-portfolio`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will publish the site at the URL shown in the Pages settings.

No paid hosting is required for this static site. Confirm the current GitHub Pages terms and account limits before relying on it for commercial use.
